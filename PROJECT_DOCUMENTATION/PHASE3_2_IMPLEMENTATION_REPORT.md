## 2. Files & Components Created (`apps/frontend/`)

### API Services & React Query Hooks
- `src/services/ocr.service.ts`: REST API client executing `POST /api/v1/ocr/process/:documentId` and `GET /api/v1/ocr/:documentId`.
- `src/hooks/useOcrResult.ts`: React Query hook fetching OCR extraction results (`queryKey: ['ocrResult', documentId]`, `staleTime: 10m`).
- `src/hooks/useProcessOcr.ts`: React Query mutation hook triggering backend Gemini Vision OCR extraction.

### Vision OCR Screen (`src/screens/documents/`)
- `SCR-DOC-04`: `OcrReviewScreen.tsx` — OCR extraction review screen featuring confidence percentage gauge, interactive manual correction form for key-value document attributes, raw extracted text container, verification submission trigger, skeleton loaders, and error state retries.
